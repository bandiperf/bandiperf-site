# Redirection site.bandiperf.fr → bandiperf.fr

Ce dépôt ne contient qu'une page qui renvoie immédiatement vers https://bandiperf.fr,
en gardant la page demandée (site.bandiperf.fr/mentions-legales.html → bandiperf.fr/mentions-legales.html).
`404.html` fait la même chose pour toutes les autres adresses. `CNAME` indique le domaine `site.bandiperf.fr`.
